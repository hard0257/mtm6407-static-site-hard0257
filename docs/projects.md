# My Projects

This page showcases some of the projects I have worked on during my Interactive Media Design program at Algonquin College.

## 01. Weekday Dinner

**Category:** Branding and Business Marketing

Weekday Dinner is a fictional meal service business designed to provide convenient meal solutions for busy individuals and families.

As part of a team, I worked on developing the brand identity, marketing strategy and visual direction of the business.

### Skills Used

- Brand identity development
- Marketing strategy
- Typography and colour selection
- Team collaboration

---

## 02. Bluewhale Fitness

**Category:** UI/UX Design

Bluewhale Fitness is a fitness application prototype designed to help users discover routes, track physical activities and save their favourite routes.

Our team focused on creating a consistent and user-friendly experience across mobile, tablet and desktop devices.

### Skills Used

- Figma
- Wireframing
- Interactive prototyping
- User experience design
- Peer feedback

---

## 03. NASA APOD

**Category:** Web Development

This project focuses on creating a website for exploring NASA's Astronomy Picture of the Day.

The project includes visual mockups and a static website prototype with search and favourites page designs.

### Skills Used

- HTML and CSS
- Responsive web design
- Visual mockups
- Git and GitHub

[View GitHub Repository](https://github.com/hard0257/mtm6302-apod-search)

## 04. News Homepage

**Category:** Front-End Development

For a Frontend Mentor challenge, I developed a responsive news homepage based on provided desktop and mobile designs.

The website includes a responsive grid layout, interactive mobile navigation and hover effects.

### Skills Used

- HTML5
- CSS Grid and Flexbox
- JavaScript
- Responsive design
